# Paper workspace

This directory holds the graduation deliverables.

- `conference/` — submission-ready conference paper and figures.
- `thesis/` — thesis chapters and appendices.
- `related-work.md` — taxonomy and coverage matrix derived from the research corpus.
- `method.md` — frozen research questions, claims, and evaluation protocol.
- `references.bib` — canonical citation keys for every cited work.

Do not hand-edit numbers that come from `results/`. Regenerate tables and
figures from experiment artifacts so the paper always matches the run data.
