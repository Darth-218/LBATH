# Results

Paper-ready outputs live here.

- `<experiment-id>.json` — machine-readable result values.
- `<experiment-id>.csv` — tabular rows for figures and appendices.
- `<experiment-id>.md` — generated Markdown tables and short interpretation.
- `figures/` — plots generated from the same JSON/CSV files.

Every table or figure in `paper/` must name the experiment ID it came from.
